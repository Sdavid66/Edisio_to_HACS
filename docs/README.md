# Ressources de documentation

Déposez ici les captures d'écran / GIF référencés par le `README.md` principal.

## `import_jeedom.png` (à fournir)

Capture (ou GIF) de l'étape **Configurer → Importer depuis Jeedom** dans Home
Assistant, idéalement montrant :

1. le menu *Configurer* avec l'entrée **Importer depuis Jeedom** ;
2. le champ **Chemin du fichier d'import (.json)** ;
3. l'écran de **récapitulatif** (nombre de récepteurs / émetteurs).

Comment la produire :

1. Installez l'intégration et placez un `edisio_import.json` dans `/config`.
2. **Paramètres → Appareils et services → Edisio → Configurer → Importer depuis Jeedom**.
3. Faites une capture de chaque écran (ou un GIF) puis enregistrez le fichier
   sous `docs/import_jeedom.png` (même nom que dans le `README.md`).

> Astuce : pour un GIF, des outils comme *Kap* (macOS), *ScreenToGif* (Windows)
> ou *Peek* (Linux) conviennent bien. Gardez une largeur ≤ 1000 px pour le poids.
